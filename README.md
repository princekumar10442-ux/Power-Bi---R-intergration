# AdventureWorks Sales & Profit Analytics Dashboard

## 📌 Project Overview

This project is developed as part of **Data Visualization Lab – Practical No. 7**. It integrates **Microsoft Power BI and R programming** to analyze AdventureWorks sales data and present business insights through an interactive dashboard.

The dashboard includes KPI cards, Power BI charts, R-based visualizations, and interactive slicers to explore sales performance across products, categories, regions, and time periods.

## 🎯 Objectives

- Analyze sales and profit performance using AdventureWorks data.
- Create an interactive dashboard using Microsoft Power BI.
- Integrate R programming for statistical data visualization.
- Explore sales trends, distributions, and relationships between variables.
- Present meaningful business insights through visual analytics.

## 🛠️ Tools and Technologies

- **Microsoft Power BI Desktop** – Dashboard development and visualization
- **R Programming** – Statistical analysis and R visualizations
- **Microsoft Excel** – Dataset storage and data source
- **DAX** – KPI calculations and measures

## 📊 Dashboard Features

### Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Customers
- Total Orders
- Profit Margin
- Average Order Value

### Power BI Visualizations
- Product-wise sales analysis
- Sales trends over time
- Region-wise sales comparison
- Category-wise sales analysis

### R Visualizations
- Sales distribution histogram
- Sales vs. profit scatter plot
- Monthly sales trend
- Sales by order quantity scatter plot

### Interactive Features
- Year slicer
- Region and category filtering
- Interactive charts and KPI cards
- Drill-down functionality where configured

## 📈 Analytical Insights

- Sales show an increasing trend during the later period represented in the dashboard.
- Sales performance varies across geographical regions.
- Bikes contribute a major share of sales among the displayed product categories.
- The scatter plot shows a positive relationship between order quantity and monthly sales in the displayed data.

*These observations are based on the dashboard visualizations and may change when filters are applied.*

## ⚙️ How to Run

1. Install Microsoft Power BI Desktop.
2. Install R from [CRAN](https://cran.r-project.org/).
3. Configure the R installation path in Power BI under **File → Options and settings → Options → R scripting**.
4. Load the AdventureWorks Excel dataset into Power BI.
5. Create the required relationships and KPI measures.
6. Add Power BI visuals and R visuals to the report.
7. Use slicers to explore the dashboard interactively.
